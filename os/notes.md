Quadrix OS 1_0000_221026

### Версии и обновления системы

- Новая нумерация версий: `1_0000_221026` — глобальная версия, номер
  обновления (две цифры), номер исправления (две цифры) и дата выпуска.
- «Параметры → Обновление»: текущая версия, проверка новых выпусков,
  загрузка и установка по кнопке. Обновление пишется в запасной слот
  системы и включается после перезагрузки; если новая версия не
  загрузится, компьютер вернётся к прежней.
- Система сама проверяет обновления через пару минут после запуска и
  затем раз в 6 часов и показывает уведомление о новой версии.
- Пакет обновления (`.qup`) можно установить из файла: двойной щелчок в
  «Файлах» открывает «Параметры → Обновление».
- Ставятся только более новые версии, подписанные ключом Quadrix.

### Wi-Fi

- Адаптеры Realtek RTL8852BE: драйвер rtw89 из Linux, поиск сетей, WPA2.
- Значок Wi-Fi на панели задач: список сетей, подключение с паролем,
  повторный поиск.

### Сеть

- Проводные карты Realtek RTL8111/8168/8169/810x/8125 и Intel
  igb/igc/I217–I219.

### NVIDIA

- Установка официального драйвера NVIDIA из файла `.run` (приложение
  «Драйвер NVIDIA»): из него берётся прошивка GSP.

Обновление ставится из «Настройки → Обновление»; образ ISO — для новой установки.
