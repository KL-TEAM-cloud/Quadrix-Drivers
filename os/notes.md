Quadrix OS 1_0504_231026

### VirtualBox

- Общий буфер обмена между Windows (или другим хостом) и Quadrix в обе
  стороны: «Устройства → Общий буфер обмена → Двунаправленный».
- Перетаскивание файлов из окна хоста в Quadrix: файл появляется там, где
  его отпустили, — на рабочем столе или в окне программы (копия — в
  «Загрузках»). «Устройства → Функция Drag and Drop → Двунаправленная».

### Браузер

- Значки сайтов и шрифты-иконки (Font Awesome и др.): псевдоэлементы
  `::before` и `::after`.
- Картинки WebP, GIF, ICO (значки сайтов) и BMP.
- Поисковая выдача DuckDuckGo и другие страницы — без чёрных рамок на
  месте прозрачных, без серых рамок на месте незагруженных картинок; поля
  ввода и кнопки в оформлении сайта.


### Браузер

- Плавная прокрутка: при прокрутке страница не рисуется заново целиком —
  сдвигается готовое изображение и дорисовывается только открывшаяся
  полоса. Кадры без изменений больше не нагружают процессор.
- Скачивание больших файлов не замораживает окно браузера и систему:
  файл пишется на диск небольшими порциями между кадрами, а файловая
  служба делает паузы для других программ.
- Страницы с большим числом картинок не тормозят при догрузке.
- Выпадающие списки, растянутые на всю ширину, показываются списком, а
  не текстом всех вариантов (DuckDuckGo).
- Скрытые боковые меню сайтов больше не видны поверх страницы.


### Быстродействие

- Система больше не замирает при скачивании больших файлов и при записи
  обновления в запасной слот. Запись на диск идёт небольшими порциями и
  крупными командами, поэтому файловая служба не замолкает на секунды, а
  вместе с ней — рабочий стол, курсор и программы.
- Обновление ОС записывается на загрузочный раздел быстрее.

Обновление ставится из «Настройки → Обновление»; образ ISO — для новой установки.
