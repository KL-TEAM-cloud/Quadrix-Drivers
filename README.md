# Quadrix-Drivers

Каталог драйверов Linux для [Quadrix OS](https://github.com/KL-TEAM-cloud/Quadrix_OS).

Драйверы из ядра Linux (исходники без изменений) собраны как загружаемые
модули для слоя драйверов Linux в Quadrix (процесс `lxdrv`) и упакованы в
подписанные пакеты `.qdrv`. Quadrix OS скачивает их сама:
**Параметры → Устройства → «Найти драйвер»** у устройства без драйвера.

## Как устроен каталог

Каждый релиз содержит:

| Файл | Что это |
|------|---------|
| `drivers.index` | список пакетов: id, версия, название, файл, PCI ID устройств, описание |
| `org.quadrix.driver.<модуль>-<версия>.qdrv` | пакет драйвера: модуль `.ko` и его PCI ID, подпись Ed25519 |
| `quadrix-linux-drivers-src.tar` | исходники слоя драйверов и драйверов Linux (GPLv2) |

Система читает последний релиз:
`https://github.com/KL-TEAM-cloud/Quadrix-Drivers/releases/latest/download/drivers.index`.
Пакеты подписаны ключом каталога; его открытая часть входит в доверенные
ключи Quadrix OS (`/system/etc/trusted-keys`).

## Как выпустить новую версию

1. В репозитории Quadrix OS собрать и подписать каталог ключом каталога:
   `QX_DRIVERS_SEED=<секрет> QX_DRIVERS_VERSION=<версия> cargo xtask drivers`.
2. Скопировать `target/quadrix/drivers/*` в `catalog/`, записать версию в
   `catalog/VERSION`, закоммитить и запушить в `main`.
3. Workflow «Релиз каталога» сам опубликует релиз `v<версия>`
   (собственный токен репозитория, секреты не нужны).

Другой путь — workflow «Каталог драйверов» в Quadrix OS (метка
`drivers-<версия>`, секреты `QX_DRIVERS_SEED` и `DRIVERS_TOKEN`).

## Выпуски Quadrix OS

Здесь же публикуется сама система (исходники Quadrix OS закрыты, а
обновления должны скачиваться без входа):

| Выпуск | Файлы |
|--------|-------|
| `os-<версия>` | образ `quadrix-<версия>.iso` и его SHA-256, `update.index`, пакет обновления `.qup` (если подписан) |
| `os-latest` | `update.index` и `.qup` последней версии — их проверяет «Параметры → Обновление» |

Выпуск: положить файлы в `os/` (`cargo xtask publish` в Quadrix OS кладёт
их в `target/quadrix/release`), записать версию в `os/VERSION`, закоммитить
и запушить в `main` — workflow «Выпуск Quadrix OS» опубликует оба выпуска
с `--latest=false`, не трогая каталог драйверов. Старый образ из `os/`
при следующем выпуске удаляется: он остаётся в своём выпуске.
